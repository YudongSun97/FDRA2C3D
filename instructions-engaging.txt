Note: the script makescript.sh contains many of these steps in a convenient form (but doesn't set paths for you).

(1) load required modules and set environment variables. On the engaging cluster, I can't compile FDRA with the newest MPI version (3.1.3) and I'm working with tech support to fix that. In the meanwhile, we use MPI 1.8.8. Since compiling can be finicky, I suggest purging loaded modules and loading only what you need:

module purge 
module load engaging/openmpi/1.8.8 

export LD_LIBRARY_PATH=/cm/shared/apps/lapack/open64/64/3.5.0:$LD_LIBRARY_PATH

(2) set paths to required libraries in the Makefile.
fdra2c has the following dependencies:

- BLAS
- HMMVP (requires BLAS, LAPACK)

BLAS: in theory, it can be loaded as a module:  (module load blas/gcc/64/1) and then set the following path in the makefile: 
BLASLIB = /cm/shared/apps/blas/open64/1/lib64/libblas.a
However, when I do this I get an error upon compiling. Therefore I downloaded BLAS and I use a local installation instead. Similarly, I use a local installation of lapack.

(3) Download and compile HMMVP. This is a modified version from Andrew's code, with an option to read externally calculated Green's functions.
	(3.1) cd work/fdra2c/external/
	(3.2) git clone git@github.com:camcat/hmmvp.git
	(3.3) mkdir lib bin
	(3.4) make mode=s (for serial version) OR make mode=omp (parallel version)

(4) Back into the fdra2c folder, clean the folder (this needs to be done especially between serial/parallel compilation) and compile:

make clean
make mode=s OR make mode=p

(5) compile a subsidiary program that adds boundary conditions to a simulation:

make mode=p add_bc

(6) To set up and run simulations from matlab, you will need functions from these other folders/repositories:

	your-path-to-fdra2c/work/fdra2c/matlab/
	https://github.mit.edu/faultmech-mit/matlab-misc (contains auxiliary functions, may or may not be needed)
	https://github.mit.edu/faultmech-mit/matlab-fdra2c (contains postprocessing functions)

(7) Here is an example workflow to set up a FDRA simulation starting from output files from a MATLAB-based FDRA simulation (fdra1.33)

  (7.1) Start with the matlab script: work/fdra2c/matlab/q2fdra2c.m to convert between fdra versions. The simulation structures must include Greens functions matrices (this can be set as an option when creating input structures for fdra1.33).
   Note that the second argument to the function: q2fdra2c is set to 1, which makes the script call HMMVP to compress Green's function matrices.

	fn='path-to-your-fdra1.33-simulation';
	s=q2fdra2c(fn,1);

  (7.2) cd to the FDRA simulation folder. The file "script.sh" contains the commands to run the FDRA simulation. You can run the script (prepend "mpirun" if you want to run it in parallel), or copy into a slurm script.

  (7.3) when the simulation is done (or even before it's finished), you can load the files in matlab using the script: matlab-fdra2c/q2load.m. The repo contains other functions that can be used to make plots.
